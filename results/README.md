# Results

Crypto3DStackCPU currently stores its strongest evidence in execution and audit workflows rather than in a broad benchmark suite.

## Current Evidence

- contract-driven execution checks via `3d_test.cpp`
- end-to-end build and run flow via `run_custom_pipeline.ps1`
- tamper rejection via `run_security_audit.ps1`
