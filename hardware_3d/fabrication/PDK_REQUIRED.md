# PDK Required

A true fabricated 3D stacked memory cannot be completed without a process design kit.

Required from foundry / fabrication partner:

- transistor device models
- SRAM compiler or memory macro library
- TSV cell library
- BEOL stack description
- interposer/RDL rules if applicable
- LEF/DEF technology files
- Liberty timing libraries
- parasitic extraction rules
- DRC deck
- LVS deck
- antenna rules
- IR/EM rules
- thermal model
- ESD rules
- seal-ring and pad-ring guidelines
- packaging constraints
- known-good-die / bonding flow details

Without these, the project can only provide RTL/specification, not real fabricated 3D silicon.
