# Foundry / 3D IC Questionnaire

Use this checklist when contacting a foundry or 3D integration partner.

## Process

- Technology node:
- Supported SRAM macros:
- TSV pitch:
- TSV resistance/capacitance:
- Maximum die stack count:
- Bonding method:
- Thermal limits:
- Wafer/die thickness:
- Known-good-die flow:

## Design Collateral

- LEF/DEF available?
- Liberty timing available?
- DRC/LVS decks available?
- Extraction deck available?
- TSV cell abstract available?
- Thermal analysis flow available?
- Signoff tool compatibility?

## Security

- Anti-probing options:
- Secure eFuse/OTP available?
- PUF support:
- Tamper sensors:
- JTAG lockout:
- Shielding layers:

## Deliverables

- GDSII/OASIS requirement:
- Netlist format:
- Timing constraints:
- Test vectors:
- Wafer/package test requirements:
